# SM-2 调度引擎：状态机与转移表（FR-4 严格实现）

## 1. 状态字段

每词一条：{ ef(初始 2.5), interval_days, due_unix, reps, lapses }
（文件布局见 srs_persistence.md；ef 以 ×100 定点存储，运算时 /100 为浮点）

自评映射：**认识 q=5，模糊 q=3，忘记 q=1**（规范锁定，不扩展）。

## 2. 转移表

说明：更新顺序固定为 先算 ef → 再算 interval → 再写 due。答错时 reps 清零、
interval 固定 1 天；答对时按 reps（本次自评**之后**的值）分档。

| # | 当前状态 | 自评 | reps | interval_days | ef | due | 附加动作 |
|---|---|---|---|---|---|---|---|
| T1 | 新词 (reps=0) | 认识 q=5 | 1 | 1 | ef + 0.10（2.5→2.6） | now+1d | state→学习中 |
| T2 | 新词 (reps=0) | 模糊 q=3 | 1 | 1 | ef + (0.1-2×0.12)=2.5→2.36 | now+1d | state→学习中 |
| T3 | 新词 (reps=0) | 忘记 q=1 | 0 | 1 | max(1.3, ef-0.2)=2.3 | now+1d | lapses+1；state 保持新词；**重插今日队列尾部**；flags.bit1=收卡强制模式A |
| T4 | 学习中 (reps=1) | q≥3 | 2 | 6 | ef + (0.1-(5-q)(0.08+(5-q)·0.02)) | now+6d | state→复习中 |
| T5 | 复习中 (reps≥2) | q≥3 | reps+1 | round(interval × ef) | 同上公式 | now+interval | |
| T6 | 任意 (reps≥1) | q<3 | 0 | 1 | max(1.3, ef-0.2) | now+1d | lapses+1；state→学习中；重插队列尾部；flags.bit1=1 |

EF 更新公式（q≥3 时，T1/T2/T4/T5 通用）：
```
ef = ef + (0.1 - (5 - q) * (0.08 + (5 - q) * 0.02))
ef = max(1.3, ef)
```
代入验证：q=5 → +0.10；q=3 → 0.1-2×0.12 = -0.14；q=1 走 T6 分支。

## 3. 每日队列构成（FR-4）

```
今日队列 = [到期词] ∪ [新词]
到期词：state≠新词 且 due_unix <= now，按 interval_days 升序
新词：state=新词，取前 N 个（N=每日新词上限，菜单可设，默认 20）
顺序：先做完到期词，再做新词；做错的词立即重插队列尾部
```

模式选择：今日到期词默认先做模式 A（看词回忆）；模式 B 由菜单切换默认
（FR-3）。模式 B 答错 → 该词 EF 降级 + 重插队尾 + 当日收卡时强制追加一次模式 A
（flags.bit1，收卡流程消费后清零）。

## 4. 收卡（当日队列清空时）

1. 扫描 flags.bit1=1 的词 → 各追加一次模式 A 复习（不计入新队列，属补救轮）；
2. 触发 .srs 合并（见 srs_persistence.md §3）；
3. 更新 .stats 当日记录；若昨日无学习记录且今日有 → streak_days = 昨日+1，
   若昨日无记录 → streak_days = 1；今日无学习行为 → 不更新（断签由 streak 停滞体现）。

## 5. 时间语义

- 所有 due/last_review 用 BM8563 RTC 的 unix 秒；interval 以"天"为单位，
  due = now + interval×86400（不按日历日零点对齐——规范即如此，简单确定）；
- 首次使用需手动设时（菜单）写入 BM8563；此后离线走时（FR-7c）；
- 单元测试注入 fake now，引擎不直接读 RTC（srs/ 纯 C 可测性要求）。
