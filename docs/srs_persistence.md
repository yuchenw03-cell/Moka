# .srs / .stats 持久化格式与断电安全

> 设计目标：64B 定长记录可直接 memcpy；写入走"日志追加 + 定时合并 + 原子替换"，
> 任意时刻断电可恢复到最近一次一致状态。

## 1. 文件组织（SD 卡 `/wordbook/`）

```
/wordbook/
├── cet6.wbx            # 词书（只读）
├── cet6.wbx.srs        # 学习状态（本文件主角）
├── cet6.wbx.srs.tmp    # 合并时的临时文件（写完后 rename 覆盖 .srs）
└── .stats              # 每日统计（词书无关，全局一份）
```

为什么按词书分 .srs 而不是全局一份：词书可增删，状态跟随词书文件走，
换词书不影响其他书的进度；文件名挂接词书，删除词书时提示是否清除进度。

## 2. .srs 文件布局

```
+---------------------------+ 0x00
│ 主记录头 (32 B)           │
├───────────────────────────┤ 0x20
│ 主记录区                  │ rec_count × 64 B，按 word_id 升序
├───────────────────────────┤
│ 日志区                    │ journal_len × 64 B，自上次合并以来
│ （追加写，无序）          │ 的原始评分记录（word_id 可重复，
│                           │  回放时后出现的覆盖先出现的）
+---------------------------+
```

### 主记录头（32 B）

| 偏移 | 大小 | 字段 | 说明 |
|---|---|---|---|
| 0x00 | 4 | magic | "SRS1" |
| 0x04 | 4 | version | = 1 |
| 0x08 | 4 | rec_count | 主记录区条数 |
| 0x0C | 4 | journal_len | 日志区条数（0 ≤ journal_len ≤ 19；到 20 触发合并） |
| 0x10 | 4 | book_word_count | 生成时词书的 word_count（换书/换版校验用） |
| 0x14 | 4 | last_compact_unix | 上次合并时间 |
| 0x18 | 4 | crc32 | 主记录区 CRC32（日志区不参与，日志是易变区） |
| 0x1C | 4 | reserved | 0 |

### 学习状态记录（64 B 定长）—— FR-5 要求

| 偏移 | 大小 | 字段 | 类型 | 说明 |
|---|---|---|---|---|
| 0x00 | 4 | word_id | u32 | |
| 0x04 | 2 | ef_x100 | u16 | EF ×100 定点存储（2.5 → 250，1.3 → 130）。为什么不用 float：C99 单测在 PC 上跑，定点保证跨平台位级一致 |
| 0x06 | 2 | reps | u16 | 连续答对次数 |
| 0x08 | 4 | interval_days | u32 | 当前间隔（天） |
| 0x0C | 4 | due_unix | u32 | 到期时间（BM8563 RTC 为基准） |
| 0x10 | 4 | last_review_unix | u32 | |
| 0x14 | 2 | lapses | u16 | 答错总次数；≥2 自动进生词本（FR-6） |
| 0x16 | 1 | state | u8 | 0=新词 1=学习中 2=复习中 3=搁置 |
| 0x17 | 1 | last_quality | u8 | 上次自评 1/3/5 |
| 0x18 | 1 | flags | u8 | bit0=今日队列重插中 bit1=收卡前强制模式A bit2=生词本（lapses≥2 派生冗余，避免扫描） |
| 0x19 | 1 | mode_hint | u8 | 上次复习模式 0=A 1=B |
| 0x1A | 6 | reserved | | 0 |
| 0x20 | 32 | reserved2 | | 0（预留后续算法字段） |

## 3. 写入策略（FR-5）

1. **每次自评**：把更新后的 64B 记录**追加**到日志区尾部（文件末尾），
   journal_len+1 回写头部。为什么追加而不是原位写：FAT/SD 原位写是最危险的
   断电窗口，追加写只可能损坏"最新一条"，开机回放时 CRC/长度校验可丢弃尾垃圾。
2. **合并触发**：journal_len 满 20，或即将休眠/关机。
3. **合并流程（断电安全关键路径）**：
   a. 回放日志区到内存态（后写覆盖先写）；
   b. 主记录区重排写全量到 `.srs.tmp`，头部 journal_len=0；
   c. fflush + fsync；
   d. `rename(.srs.tmp, .srs)`（FAT 的 rename 是目录项替换，原子性足够）；
   e. 再 fsync 目录（打开目录 fsync——ESP-IDF 下用 fsync(fileno(dir)) 不可行，
      改用 reopen .srs + fsync 作为替代兜底）。
4. **开机恢复**：若发现 `.srs.tmp` 存在 → 上次合并中途断电 → 校验 tmp 的
   CRC，合法则 rename 转正，非法则删除 tmp 保留旧 .srs。

## 4. .stats 每日统计（FR-5 / FR-6）

文件头 16B：magic "STA1" + version + rec_count + crc32（全文件）。
之后每条 32B 定长，按日期升序：

| 偏移 | 大小 | 字段 | 说明 |
|---|---|---|---|
| 0x00 | 4 | date_yyyymmdd | u32，如 20260928 |
| 0x04 | 2 | new_learned | 当日新学数 |
| 0x06 | 2 | reviewed | 当日复习数 |
| 0x08 | 2 | correct | 答对数 |
| 0x0A | 2 | wrong | 答错数 |
| 0x0C | 2 | streak_days | 截至当日的连续打卡天数（当日有学习行为才+1） |
| 0x0E | 2 | study_secs | 当日学习秒数 |
| 0x10 | 16 | reserved | 0 |

写入策略同 .srs：当日记录原位更新（同一天只一条），跨天追加新条。
柱状图取最近 30 条（FR-6）。
